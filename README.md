## 📖 About

HWiNFO is a detailed system information and monitoring tool developed by Martin Malík at REALiX s.r.o. It reads data from motherboards, CPUs, GPUs, storage drives, memory modules and cooling sensors, then presents everything in a single tree view or a compact sensor window. Recent builds add expanded support for newer CPU generations, updated sensor libraries and improved reporting for hybrid graphics laptops.

If you came looking for a HWiNFO download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The utility runs in a read only mode by default, so it only observes hardware telemetry unless you intentionally open the sensor logging tools.

**Good for:** PC builders · overclockers · system integrators · hardware reviewers · IT technicians · temperature monitoring · driver and firmware version checks

## 🔑 Features

| Feature | Description |
| --- | --- |
| 🌡️ **Live sensor readouts** | Tracks CPU, GPU, motherboard and drive temperatures in real time. |
| ⚙️ **Detailed component report** | Lists CPU model, cache layout, RAM timings, GPU specs and BIOS revision. |
| 📊 **Fan and voltage monitoring** | Shows fan RPM, core voltage, power draw and clock speeds per core. |
| 🧠 **Memory and storage info** | Reports RAM module part numbers, SPD data and drive SMART health. |
| 📈 **Graph and logging tools** | Plots sensor history to screen or writes it to a CSV log file. |
| 🖥️ **Compact sensor view** | Offers a small always on top panel for watching temps during load. |
| 🔍 **Report export** | Saves a full hardware report as text, HTML or CSV for sharing. |
| 🧩 **Portable mode** | Can run from a folder without a permanent installation. |
| 🔄 **Regular database updates** | Sensor and device databases refresh with each new build. |

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Sensors show no readings | Close other hardware monitors and restart HWiNFO, some drivers conflict. |
| Missing GPU temperature | Update your graphics driver, then rescan sensors. |
| App needs administrator rights | Right click the shortcut and choose **Run as administrator**. |
| Sensor window flickers | Switch to the compact view from the Sensors menu. |
| Log file not written | Pick a folder where your user account has write access. |
| Report export looks incomplete | Let the scan finish fully before saving the report. |
